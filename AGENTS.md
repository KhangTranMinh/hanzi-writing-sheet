# Project rules

1. Before every commit, update `web/version.json` using `YY.MM.DD.xx` and the current date in the `Asia/Ho_Chi_Minh` timezone. If the date matches the existing version, increment the build number; if the date has changed, use the new date and start the build number at `01`. Include the version change in the same commit. Update the `v` query values on the practice link and stylesheet in `web/index.html`, and on the stylesheet and script in `web/practice/index.html`, to match the new version so browsers fetch updated assets.

2. Git commits are local and do not need a token. For authenticated Git operations and GitHub CLI commands, run `python3 scripts/github/github.py git <arguments>` or `python3 scripts/github/github.py gh <arguments>`. The wrapper reads `GITHUB_TOKEN` from the ignored root `.env`, provides it to Git through `GIT_ASKPASS` and to GitHub CLI through `GH_TOKEN`, and does not require a local credential helper. Keep the token out of command output, commit history, Git config, remote URLs, and tracked files.

3. After completing changes to the web app, run or restart the local web server and open the relevant page in both a desktop browser window and a separate mobile-sized browser window for review. Use a mobile viewport or device emulation when available, and report if the mobile view could not be opened. Do not commit or deploy solely because the web app was changed.

4. After completing changes to the React Native app, run or restart it locally using the project's Expo workflow and open it on an available simulator, emulator, or connected device. If the required tools or device are unavailable, report what could not be run. Do not publish or deploy solely because the app was changed.

5. Treat `shared/data/` as the source of truth for web and React Native lessons, practice cards, and worksheet stroke data. Update the shared files, then run `python3 scripts/shared_data/publish_shared_data.py` or use the documented startup commands before testing or committing generated copies. The `0000-0000.json` lesson is a template and must not appear in the lesson catalog. For mobile releases, bundle the updated data in a new app build; it is not fetched automatically.
