# Project rules

1. Before every commit, update `web/version.json` using `YY.MM.DD.xx` and the current date in the `Asia/Ho_Chi_Minh` timezone. If the date matches the existing version, increment the build number; if the date has changed, use the new date and start the build number at `01`. Include the version change in the same commit. Update the `v` query values on the practice link and stylesheet in `web/index.html`, and on the stylesheet and script in `web/practice.html`, to match the new version so browsers fetch updated assets.
2. For Git operations against this project's GitHub remote, use `GITHUB_TOKEN` from the repository root `.env` when authentication is needed. The local Git credential helper in `private/git-credential-env.py` is configured to provide it for this repository; `private/` and `.env` are ignored by Git. Keep the token out of command output, commit history, Git config, remote URLs, and other tracked files. If the helper is unavailable, configure a local credential helper that reads the token from `.env` without exposing or storing its value in tracked files.
