# Project rules

1. Before every commit, run `python3 scripts/web/version.py --bump` and include all resulting changes in the same commit. The version in `web/version.json` uses `YY.MM.DD.xx` and the current date in the `Asia/Ho_Chi_Minh` timezone: increment the build number if the date matches, or start at `01` on a new date. Ensure versioned URLs match across `web/index.html` (stylesheet and links to all four pages), `web/worksheet/index.html` (stylesheet and script), `web/lessons/index.html` (stylesheet and script), `web/practice/index.html` (stylesheet and script), and `web/translation-exercises/index.html` (stylesheet and script). Run `python3 scripts/web/version.py --check` to verify them; add a `v` query when a required URL does not have one, because the script only synchronizes existing queries.

2. Git commits are local and do not need a token. For authenticated Git operations and GitHub CLI commands, run `python3 scripts/github/github.py git <arguments>` or `python3 scripts/github/github.py gh <arguments>`. The wrapper reads `GITHUB_TOKEN` from the ignored root `.env`, provides it to Git through `GIT_ASKPASS` and to GitHub CLI through `GH_TOKEN`, and does not require a local credential helper. Keep the token out of command output, commit history, Git config, remote URLs, and tracked files.

3. After completing changes to the web app, run or restart the local web server and open the relevant page in the system's default browser, using both a desktop window and a separate mobile-sized window for review. Use a mobile viewport or device emulation when available, and report if the mobile view could not be opened. Do not commit or deploy solely because the web app was changed.

4. The requirement to run the React Native app locally after changes is temporarily suspended. Do not publish or deploy solely because the app was changed.

5. Treat `shared/data/` as the source of truth for web and React Native lessons, practice cards, and worksheet stroke data. Each sync replaces `web/data/` and `react-native/data/` entirely with `shared/data/`. Update the shared files, then run `python3 scripts/shared_data/publish_shared_data.py` or use the documented startup commands before testing or committing generated copies. The `0000-0000.json` lesson is a template and must not appear in the lesson catalog. For mobile releases, bundle the updated data in a new app build; it is not fetched automatically.
