# Project rules

1. Before every commit, update `web/version.json` using `YY.MM.DD.xx` and the current date in the `Asia/Ho_Chi_Minh` timezone. If the date matches the existing version, increment the build number; if the date has changed, use the new date and start the build number at `01`. Include the version change in the same commit. Update the `v` query values on the practice link and stylesheet in `web/index.html`, and on the stylesheet and script in `web/practice/index.html`, to match the new version so browsers fetch updated assets.
2. Git commits are local and do not need a token. For authenticated Git operations and GitHub CLI commands, run `python3 scripts/github/github.py git <arguments>` or `python3 scripts/github/github.py gh <arguments>`. The wrapper reads `GITHUB_TOKEN` from the ignored root `.env`, provides it to Git through `GIT_ASKPASS` and to GitHub CLI through `GH_TOKEN`, and does not require a local credential helper. Keep the token out of command output, commit history, Git config, remote URLs, and tracked files.
