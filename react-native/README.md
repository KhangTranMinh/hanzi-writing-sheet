# React Native app

This is an independent Expo + React Native project for Android and iOS. It does not share runtime code or data files with `local/` or `web/`.

## Start developing

```sh
npm start
```

Open the project with Expo Go to preview the starter app. To start Expo and open the Android emulator or iOS simulator, use:

```sh
npm run android
npm run ios
```

The Android/iOS scripts start Expo and open the selected simulator or device. After installing a development build, start the project with `npx expo start --dev-client` to open it in that app instead of Expo Go.

The app is currently the blank TypeScript starter; worksheet screens, PDF generation, and app-specific assets have not been added yet.
